# 日日有樂原聲帶連結頁（ost）

> 日日有樂 SunMoon Music｜配樂作曲家 蔡宜均
> 部署網址：https://sunmoonmusicstudio-tsai.github.io/ost/

每張原聲帶一個資料夾，裡面一頁 `index.html` 列出所有串流平台按鈕，給社群貼文當「一個連結全平台」用。

| 專輯 | 網址 |
|---|---|
| 《恨女的逆襲》電影原聲帶 A Dance with Rainbows | https://sunmoonmusicstudio-tsai.github.io/ost/a-dance-with-rainbows/ |

## 新增專輯

1. 複製 `a-dance-with-rainbows/` 成新資料夾（英文小寫、連字號）
2. 換 `cover.jpg`（1200×1200 JPG）、改標題與平台連結、改 `og:image` 與 `og:url` 的路徑
3. 在根目錄 `index.html` 加一列
4. `git push`，1 到 2 分鐘後自動上線

## 部署方式

GitHub Pages，main 分支、根目錄。帳號 `sunmoonmusicstudio-tsai`。
